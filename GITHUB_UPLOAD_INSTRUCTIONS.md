# Publish Marble Summit v1.1

1. Create a public repository in your `jkramer-cloud` account named `marble-summit`.
2. Upload **index.html** to the root, along with README.md and CHANGELOG.md if desired. Commit to `main`.
3. In **Settings > Pages**, choose **Deploy from a branch**, `main`, `/ (root)`; save.
4. Open the GitHub Pages URL shown in Settings > Pages. For the specified account/name it should be `https://jkramer-cloud.github.io/marble-summit/` once published.
5. Test the Classic and Summit boards. The v1.1 board includes START, HOME ENTRY, and shortcut route guides.

The separate Naches Learning Hub v31.38 ZIP already includes the Marble Summit entry. Publish this game first so the Hub link has a working destination, then upload the Hub update to the existing Learning Hub repository. Do not upload the game `index.html` to the Hub repository.
