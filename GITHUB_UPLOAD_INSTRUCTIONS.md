# Installing Marble Summit on GitHub Pages

## Existing repository

1. Download and extract `MARBLE_SUMMIT_V1_0_GITHUB_READY.zip`.
2. Open your Marble Summit game repository on GitHub.
3. Upload the included **index.html** to the repository's root (replace any old index.html).
4. Commit the changes to the main branch.
5. If GitHub Pages is already enabled for the repository, refresh the published site after deployment.

## New repository

1. In GitHub, create a public repository, e.g. `marble-summit`.
2. Upload **index.html** (and optionally README.md and screenshot previews) to its root, then commit.
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch** and select `main` with the `/ (root)` folder.
4. Open the Pages site shown under Settings → Pages.

The actual Pages URL depends on the account and repository. Do not guess it; copy the URL from GitHub.

## Adding the activity to the Naches Learning Hub

After the game is published, add a regular game/activity link on the Learning Hub that points to the published Pages URL. You can use the title and short description from `HUB_LISTING.txt`. This ZIP is a standalone game and does **not** automatically change the Hub's index or activities.json.

## Recommended first play test

- Begin with **Classic**, 1 Human and 3 Computers; roll and launch a marble on 1 or 6.
- Play the seven-lesson Tutorial, especially the capture and center exercises.
- Launch a Summit board with 5 Computers or 6 Computers to test the automated turns.
- Toggle Full Screen, Sounds, Paths, and Angled View.
- Refresh the page after a move to confirm that Resume Saved Game is available.
