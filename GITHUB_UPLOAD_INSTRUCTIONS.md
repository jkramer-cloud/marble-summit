# GitHub Pages upload — Marble Summit v2

1. Open the `marble-summit` repository on GitHub (or create it if needed).
2. Unzip the v2 package on your computer.
3. Upload or replace `index.html` in the repository root, along with the updated `README.md` if desired.
4. Commit the changes to the `main` branch.
5. In Settings → Pages, set Deploy from a branch: `main` / `(root)` if not already configured.
6. Open `https://jkramer-cloud.github.io/marble-summit/` and refresh (Ctrl+Shift+R) to see the new design.

The preview PNGs and documentation are optional for the website; `index.html` alone contains the complete playable game.

This game ZIP does not overwrite the Learning Hub repository. The existing Hub card continues to link to the same game URL, so no Hub update is needed to play v2. The v1-style Hub thumbnail can be updated separately.
