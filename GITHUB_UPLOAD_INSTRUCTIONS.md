# Publish Marble Summit v4.0 on GitHub Pages

1. Open your existing `marble-summit` repository on GitHub.
2. Replace the repository's top-level `index.html` with the one in this ZIP.
3. Commit the change to the branch currently configured for GitHub Pages (`main` if unchanged).
4. Confirm **Settings → Pages** uses that branch and the `/ (root)` folder.
5. Open or refresh the existing Pages link. For the previously used account/repository naming, this should be `https://jkramer-cloud.github.io/marble-summit/` once published.
6. If you see old graphics, refresh the page without cache (Ctrl+Shift+R in Windows).

Only `index.html` is necessary for the game to run. The README, changelog, and screenshots are optional repository documentation.

The Learning Hub link does not need updating if the GitHub Pages address stays the same. The Learning Hub *card artwork* is separate; replacing this game does not update that card.
