# Marble Summit v5.0

Marble Summit is a browser-based marble race game inspired by classic Aggravation-style boards.

## What's new in v5
- Triangle / Square / Pentagon / Hexagon / Heptagon / Octagon board layouts
- Corner-style base trays
- Corrected home-entry placement compared with prior versions
- Larger boards (5–8 corners) use a 3-spot upper shortcut ring
- Overhead view by default with optional rotating 3D mode

## Files
- `index.html` — main game file for GitHub Pages or local play
- `CHANGELOG.md` — version history
- `GITHUB_UPLOAD_INSTRUCTIONS.md` — quick setup directions

## Notes
This build keeps the existing gameplay engine but redesigns the board layouts and shortcut structure. It should work on GitHub Pages as a static site.
